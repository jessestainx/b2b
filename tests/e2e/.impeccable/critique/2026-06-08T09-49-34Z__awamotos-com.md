## Priority Issues

**[P1] "Mais Vendidos" pode exibir fallback de novidades, não giro real**
- **Why:** `bestsellerproduct/bestsellerproduct_config/enabled = 0`; `HomeBestsellerCarousel` cai em `buildNewestFallbackCollection()` sem sinal visual. Alex confia no rótulo para repor o que mais vende.
- **Fix:** Habilitar módulo bestseller **ou** rotular fallback ("Novidades em destaque") **ou** usar SalesIntelligence/ERP para ranking real.
- **Suggested command:** operacional (config) + `/impeccable harden home`

**[P2] Chrome do carrossel (nav + progress) ausente no HTML inicial**
- **Why:** `awa-scroll-carousel.js` injeta `.awa-owl-nav` após load; sem JS, visitante só descobre swipe por acidente. Casey no 3G ou com JS bloqueado perde affordance.
- **Fix:** SSR mínimo de nav/progress nos templates de shelf **ou** `<noscript>` fallback em grid estático.
- **Suggested command:** `/impeccable harden home`

**[P2] Muro cognitivo: 25 CTAs idênticos "Ver preços"**
- **Why:** Banner único ajuda, mas cada card repete a mesma ação; carga visual alta na rolagem longa.
- **Fix:** Após 1º shelf, reduzir CTA a link textual nos compact **ou** agrupar gate só no card hover/focus.
- **Suggested command:** `/impeccable distill home`

**[P2] `product-info-cart` permanece no DOM para visitante**
- **Why:** Oculto via `display:none` (§70), mas 25 blocos no HTML; leitor de tela pode anunciar estrutura fantasma; markup mais pesado que o necessário.
- **Fix:** Remover botão add-to-cart no template para guest (plugin PHP) em vez de só CSS.
- **Suggested command:** `/impeccable harden home`

**[P3] Imagens placeholder no catálogo (≈11 na home)**
- **Why:** Cards com foto genérica reduzem confiança e quebram hierarquia visual da vitrine.
- **Fix:** Dado de catálogo/ERP, não CSS; priorizar SKUs visíveis na home.
- **Suggested command:** operacional (catálogo)
