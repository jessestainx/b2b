## Detailed Findings

### P2 — Minor

**[P2] CSS inline global ainda pesado na PLP**
- **Location:** `awa-head-preload.phtml` — blocos `awa-header-impeccable-critical-global` (~22 KB), `awa-cls-nav-fix` (~20 KB), etc.
- **Category:** Performance
- **Impact:** Parse bloqueante no critical path; PLP herda ~117 KB inline mesmo com PLP-specific externalizado
- **Medição live:** 8 blocos `<style>`, 116 744 bytes inline total
- **Recommendation:** Extrair regras estáveis do header critical para bundle cacheável por rota; manter inline só above-fold mínimo
- **Suggested command:** `/impeccable optimize PLP` (ou escopo header global)

**[P2] Stack de 4 bundles CSS PLP com overlap**
- **Location:** `awa-plp-critical-fixes` (9 KB) + `awa-plp-ui-promax` (10 KB) + `awa-bundle-async-distill-lock` (9 KB) + `awa-plp-final-polish` (51 KB)
- **Category:** Performance / Theming
- **Impact:** Downloads paralelos OK, mas especificidade competindo; `final-polish` é 64% do payload PLP
- **Recommendation:** `/impeccable distill PLP` — fundir promax + distill-lock estáveis em pass2 LESS; reduzir final-polish ao que pass2 não cobre
- **Suggested command:** `/impeccable distill PLP`

**[P2] Pager desktop abaixo de 44×44px**
- **Location:** `_awa-plp-consistency-pass2-2026-06.less` L134–139 — `min-width/height: 36px`
- **Category:** Responsive / Accessibility
- **Impact:** WCAG 2.5.5 (Target Size) — 44px só em `pointer: coarse`; desktop trackpad/touchscreen híbrido pode ter alvos pequenos
- **WCAG:** 2.5.5 (Level AAA; boa prática AA em touch)
- **Recommendation:** Subir default para 40–44px ou manter 36px com padding hit-area expandida via `::before`
- **Suggested command:** `/impeccable adapt PLP`

**[P2] Três imagens com alt vazio ou ausente**
- **Location:** Live `carcacas.html` — 46 `<img>`, 3 sem alt útil
- **Category:** Accessibility
- **Impact:** Leitores de tela ignoram contexto visual; WCAG 1.1.1
- **WCAG:** 1.1.1 (Level A)
- **Recommendation:** Auditar templates de produto/categoria; `alt` descritivo ou `alt=""` + `aria-hidden` se decorativa
- **Suggested command:** `/impeccable harden PLP`

### P3 — Polish

**[P3] Glassmorphism residual em final-polish**
- **Location:** `awa-plp-final-polish.css` — `backdrop-filter: blur(8–16px)`, `--awa-glass-bg`
- **Category:** Anti-Pattern / Performance
- **Impact:** Paint cost em scroll; tell técnico de “premium UI” genérico
- **Recommendation:** Substituir por `color-mix` sólido sem blur onde possível
- **Suggested command:** `/impeccable quieter PLP`

**[P3] Footer tokens slate no head-preload global**
- **Location:** `awa-head-preload.phtml` — `#f9fafb`, `#f1f5f9` em fallbacks footer
- **Category:** Theming
- **Impact:** Drift sutil vs `--awa-bg-soft` / `--awa-border` em páginas que incluem footer na PLP
- **Recommendation:** Alinhar fallbacks footer aos tokens AWA canônicos
- **Suggested command:** `/impeccable colorize` (escopo global header/footer)

**[P3] `modes-label-bottom` ausente quando toolbar inferior não expõe modes**
- **Location:** Toolbar inferior — só pager + count
- **Category:** Accessibility
- **Impact:** Comportamento correto (0 duplicatas), mas inconsistência de slots entre top/bottom
- **Recommendation:** Documentar contrato de slots; opcional `aria-hidden` no container modes vazio
- **Suggested command:** `/impeccable harden PLP`

## Patterns & Systemic Issues

1. **Camadas CSS legadas vs LESS compilado:** promax + final-polish + distill-lock coexistem com `_awa-plp-consistency-pass2-2026-06.less` — drift resolvido em tokens, mas não em arquitetura de bundles.
2. **Critical path compartilhado:** PLP paga o custo do header inline global (~65% do inline CSS) sem benefício direto do grid de produtos.
3. **Fallback hex como segunda linha:** padrão `var(--awa-*, #canonical)` está correto; hex soltos eliminados nos bundles PLP auditados.
