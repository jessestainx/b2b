## Detailed Findings

### P0 — Blocking

**[P0] Express checkout redireciona guest para o carrinho**
- **Location:** `https://awamotos.com/expresscheckout.html` → `Location: https://awamotos.com/checkout/cart/`
- **Category:** Responsive / fluxo (task completion)
- **Impact:** visitante ou sessão expirada não consegue iniciar checkout; `/checkout/` também redireciona para express e depois para cart.
- **WCAG:** não aplicável diretamente; bloqueio de tarefa comercial.
- **Recommendation:** validar plugin B2B/guest gate; garantir rota OPC para guest com carrinho vazio mostre login ou empty-state, não loop para cart.
- **Suggested command:** `/impeccable harden checkout`

### P1 — Major

**[P1] Bundle Promax no carrinho (performance)**
- **Location:** HTML live linha ~875: `awa-ui-promax-bundle.min.css` via `awa-head-preload.phtml` (~1214)
- **Category:** Performance
- **Impact:** ~119KB CSS deferido ainda parseado no carrinho; contradiz remoção do loader no `checkout_cart_index.xml`.
- **Recommendation:** condicionar `$__promaxBundleUrl` a `body` checkout/OPC/PLP, excluir `checkout-cart-index`.
- **Suggested command:** `/impeccable optimize carrinho`

**[P1] Side-stripe borders nos bundles globais**
- **Location:** ex. `awa-defer-global-bundle.css` (várias `border-inline-start: 3–4px`), `awa-vertical-menu-modern.css`, `awa-flex-grid-flow.css`
- **Category:** Anti-Pattern
- **Impact:** leitura “alerta SaaS”, inconsistente com terminal B2B/carrinho.
- **Recommendation:** substituir por `background` tint ou borda completa 1px; consolidar no terminal Impeccable.
- **Suggested command:** `/impeccable layout menu-departamentos`

**[P1] Hierarquia H2 inconsistente (home)**
- **Location:** `https://awamotos.com/` — runtime: `22.75px, 22px, 24.5px, 21px`
- **Category:** Accessibility / Theming (legibilidade)
- **Impact:** ritmo tipográfico irregular; scan de seções mais difícil.
- **Evidence:** `tests/e2e/reports/deep-audit/.issues-2026-05-30T23-03-15/home.json`
- **Screenshot:** `tests/e2e/screenshots/deep-audit/2026-05-30T23-03-15/chromium-desktop-1280/home-full.png`
- **Recommendation:** aplicar escala única em `awa-commerce-impeccable-refine.css` (v4 já no repo) e publicar em static.
- **Suggested command:** `/impeccable typeset home`

1. **Camada terminal Impeccable funciona** onde há CSS dedicado (carrinho 19/20, B2B dashboard 20/20); fora disso vencem bundles de 5MB+ async (`styles-m`, defer-global).

4. **Deploy estático** termina com “Area code is not set” após 100% — exige `cp` manual para `pub/static` (risco de drift live/repo).
