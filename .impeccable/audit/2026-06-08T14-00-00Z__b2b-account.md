## Detailed Findings

### P2 — Minor

**[P2-Perf] `pages.css` monolítico em todas as rotas `customer_account`**
- **Location:** `customer_account.xml` L6; `pages.css` (~51KB, quickorder + shoppinglist + approval + credit + reorder)
- **Category:** Performance
- **Impact:** parse CSS de seções não usadas (ex. quickorder em `/b2b/credit`)
- **Recommendation:** split em `pages-core.css` + imports por rota, ou `@layer` com carregamento condicional por body class
- **Suggested command:** `/impeccable optimize b2b/account`

**[P2-Perf] Late CSS async e FOUC potencial**
- **Location:** `b2b-pages-css.phtml` (`media="print"` + `onload`); `awa-b2b-pages-late.css` (56KB)
- **Category:** Performance / Responsive
- **Impact:** flash breve de estilos de nav/tabelas se regra existir só no late; mitigado porque `account-b2b.css` cobre SSOT crítico
- **Recommendation:** auditar diff late vs account-b2b; migrar regras above-fold para camada bloqueante ou `preload` se FOUC reportado
- **Suggested command:** `/impeccable polish b2b/account`

**[P2-Theming] Hex hardcoded em `pages.css`**
- **Location:** ~64 ocorrências `#...` (estados reorder, approval, quickorder)
- **Category:** Theming
- **Impact:** drift de cor; dark mode inexistente não quebra hoje
- **Recommendation:** mapear para `--awa-*` / semantic tokens de erro/sucesso
- **Suggested command:** `/impeccable colorize b2b/account`

**[P2-A11y] Título do menu mobile usa `role="button"` em `.block-title`**
- **Location:** `nav-mobile.js` L73–74
- **Category:** Accessibility
- **Impact:** leitor de tela pode anunciar "button" em elemento não-button; funciona com Enter/Space
- **Recommendation:** converter título para `<button type="button">` estilizado ou `aria-controls` no wrapper
- **Suggested command:** `/impeccable harden b2b/account`

### P3 — Polish

**[P3-A11y] `thead th` uppercase 11px em tabelas conta**
- **Location:** `account-b2b.css` L356–361
- **Impact:** aceitável como label curto; contraste ok em fundo tintado

**[P3-A11y] Skip link ausente em páginas account**
- **Impact:** teclado tabula header antes do conteúdo; site-wide

**[P3-A11y] `aria-live` global + status por card em reorder**
- **Location:** `reorder.phtml` L13 + status por card
- **Impact:** anúncios SR podem ser verbosos; funcional

- **Location:** `nav-mobile.js` L96–98 (early return se não mobile no load)
- **Impact:** rotação desktop→mobile sem reload não monta accordion
- **Suggested command:** `/impeccable harden b2b/account`
