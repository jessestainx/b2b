## Detailed Findings

### P1 — Major

**[P1] ID duplicado `paging-label`**
- **Location:** Pager superior e inferior — `vendor/magento/module-theme/view/frontend/templates/html/pager.phtml` (sem override no tema filho)
- **Category:** Accessibility
- **Impact:** `aria-labelledby="paging-label"` ambíguo para leitores de tela; viola HTML id único + WCAG 4.1.1
- **WCAG:** 4.1.1 (Level A)
- **Recommendation:** Override `pager.phtml` no tema filho com sufixo por slot (`paging-label-top` / `paging-label-bottom`), espelhando padrão `modes-label-{slot}`
- **Suggested command:** `/impeccable harden PLP`

### P2 — Minor

**[P2] Payload HTML e CSS inline elevados**
- **Location:** `awa-head-preload.phtml` + blocos critical v4/terminal-sync (~148 KB inline em 10 `<style>`)
- **Category:** Performance
- **Impact:** Parse HTML prolongado em 3G; FCP depende de critical path longo (458 KB documento)
- **Recommendation:** Extrair regras estáveis do terminal-sync para LESS compilado; manter inline só o mínimo above-fold por rota
- **Suggested command:** `/impeccable optimize PLP`

**[P2] Quatro camadas CSS na PLP**
- **Location:** `styles-l` (pass2 LESS) + `awa-plp-ui-promax` + `awa-plp-final-polish` + `awa-bundle-async-distill-lock` (+ fila async global)
- **Category:** Theming / Performance
- **Impact:** Drift de tokens (`#333`, `#666` em promax vs `var(--awa-*)`); downloads e especificidade competindo
- **Recommendation:** Migrar regras úteis de promax/final-polish para `_awa-plp-consistency-pass2-2026-06.less`; desregistrar bundles legados do layout
- **Suggested command:** `/impeccable colorize PLP`

**[P2] Hex hard-coded no critical inline**
- **Location:** `awa-head-preload.phtml` — 31 valores hex distintos no CSS inline (ex.: `#475569`, `#f9fafb`)
- **Category:** Theming
- **Impact:** Diverge de DESIGN.md (lei no-hex); difícil manter contraste consistente
- **Recommendation:** Substituir por tokens `--awa-*` / `@awa-color-*` já definidos em `_design-system.less`
- **Suggested command:** `/impeccable colorize PLP`

**[P2] Pager desktop abaixo de 44px**
- **Location:** `_awa-plp-consistency-pass2-2026-06.less` — `.pages .item a` com `min-height: 36px`
- **Category:** Responsive
- **Impact:** WCAG 2.5.5 em tablets/híbridos touch
- **Recommendation:** `min-height: 44px` em `@media (pointer: coarse)` ou globalmente na PLP
- **Suggested command:** `/impeccable adapt PLP`

**[P2] Title case / acentuação ERP**
- **Location:** `list.phtml` / nomes de produto — ex.: "Carcaca Inferior CG Titan..."
- **Category:** Accessibility + Copy
- **Impact:** Leitura e confiança B2B; plugin atual só trata ALL CAPS
- **Recommendation:** Estender normalização PT (NFC + dicionário `Carcaca` → `Carcaça`)
- **Suggested command:** `/impeccable typeset PLP`

**[P2] Imagens com `alt=""` (3 ocorrências)**
- **Location:** PLP live — swatches/decoração
- **Category:** Accessibility
- **Impact:** OK se decorativo com `aria-hidden`; senão 1.1.1
- **Recommendation:** Confirmar decorativo → `role="presentation"`; swatches funcionais → alt descritivo
- **Suggested command:** `/impeccable polish PLP`

### P3 — Polish

**[P3] Ausência de spec E2E PLP no CI**
- **Location:** `tests/e2e/specs/` — sem `category-plp.spec.ts`
- **Category:** Hardening
- **Impact:** Regressões toolbar/hero/banner não bloqueiam merge
- **Suggested command:** `/impeccable harden PLP`

**[P3] 95 tags `<script>`**

**[P3] Tokens glass em `awa-plp-final-polish`**
- **Category:** Anti-Pattern
- **Impact:** Baixo; variáveis `--awa-glass-*` pouco visíveis na PLP atual
- **Suggested command:** `/impeccable quieter PLP`

**[P3] Hero compacto mobile**
- **Category:** Responsive
- **Impact:** Contagem "27 produtos" pode ficar visualmente comprimida no overlay
- **Suggested command:** `/impeccable layout PLP`

## Patterns & Systemic Issues

1. **IDs únicos por slot** resolvido para toolbar (`modes-label-top`, `toolbar-amount-top`); pager ainda usa template core sem slot.
2. **Crescimento do critical inline** — cada rodada impeccable adiciona blocos sync no head; precisa de estratégia de consolidação em LESS.
3. **Stack CSS PLP** — pass2 + promax + final-polish + distill-lock + fila global (~17 bundles `awa-*` na rota).
4. **Gate B2B por card** substituído por banner único + CTA "Ver preço atacado" inline nos cards (comportamento esperado para guest).
