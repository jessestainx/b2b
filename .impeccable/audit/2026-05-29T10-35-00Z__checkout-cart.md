## Detailed Findings

### [P1] Semântica de tabela quebrada no mobile
- **Location:** `awa-cart-polish.css` (display:block em table/tbody/tr)
- **Category:** Accessibility
- **Impact:** Leitores de tela podem não anunciar relação linha/coluna
- **WCAG:** 1.3.1 Info and Relationships
- **Recommendation:** `role="table"` + `role="rowgroup"` ou lista semântica
- **Command:** `/impeccable harden carrinho a11y mobile`

### [P2] CSS do handle cart pesado
- **Location:** `cart-checkout-premium.css` (~138KB) + polish + terminal
- **Category:** Performance
- **Impact:** Parse CSS em 3G; premium é compartilhado com checkout
- **Command:** `/impeccable optimize carrinho css`

### [P2] Rótulos mobile 11px
- **Location:** `awa-cart-polish.css` td::before data-th
- **Category:** Responsive / A11y
- **Impact:** Texto secundário pequeno em telas estreitas
- **Command:** `/impeccable typeset carrinho mobile`

### [P2] Cupom: título pode vir em EN
- **Location:** `vendor/.../coupon.phtml` (Magento core)
- **Category:** Accessibility / Copy
- **Command:** `/impeccable clarify cupom carrinho`

### [P3] Focus ring hardcoded rgb()
- **Location:** `awa-cart-polish.css` (vários focus-visible)
- **Category:** Theming
- **Command:** `/impeccable document` (tokenizar focus ring)

### [P3] Stepper não desabilita botão no mínimo
- **Location:** `awa-qty-control.js`
- **Category:** UX / Error prevention
- **Command:** `/impeccable harden stepper carrinho`
