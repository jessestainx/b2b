## Anti-Patterns Verdict

**LLM assessment:** Parcialmente autêntico. Não é SaaS genérico — copy B2B brasileiro, vitrines por linha de negócio e header orientado à busca são diferenciais reais. Ainda carrega DNA marketplace Ayo: hero Swiper autoplay, faixa de 4 benefits com métrica “5.000+ itens”, e 4+ shelves idênticas geram repetição de outlet, não de balcão confiável.

**Deterministic scan:** Indisponível — `detect.mjs` falhou (`impeccable-config.mjs` ausente). Evidência manual do código:

- **Contraste newsletter (RESOLVIDO no código, não validado live):** `h2.awa-newsletter-title` tinha `#fff` sobre fundo branco (IMP-07). Fix r5 aplica `#1a1a1a` com especificidade 3× `#html-body`.
- **Contagem de estoque oculta:** `top-home.phtml` L247 — `.awa-category-carousel__count.awa-sr-only`.
- **Cognitive load:** 5/8 falhas no checklist (ação primária, hierarquia, progressive disclosure, consistência, densidade mobile).

**Visual overlays:** Não disponível. Site retorna HTTP 503 (página nginx de manutenção); browser MCP indisponível nesta sessão. Magento `maintenance:status` = disabled — bloqueio é camada nginx, não Magento.

## Overall Impression

A homepage **sabe o que é** (distribuidora B2B de motopecas) e o copy prova isso. O maior gap é entre a promessa “Reliable Parts Counter” e a experiência real: marketing hero no topo, estoque escondido no meio, recompra ausente para quem mais compra. A correção de contraste da newsletter é sintoma de dívida de cascata CSS — funcional, mas frágil.

## What's Working

1. **Copy B2B específico** — “Reposição mais pedida por lojistas”, aviso de preço guest, promo bar corporativa.
2. **Eixo catálogo bem nomeado** — Categorias + vitrines Bauletos/Retrovisores falam a linguagem do revendedor.
3. **Header orientado à tarefa** — Busca central, menu vertical, badge B2B, minicart acessível.

## Priority Issues

### [P0] Contagens de estoque invisíveis no carrossel de categorias
- **What:** Product count renderizado apenas em `.awa-sr-only` (`top-home.phtml` L247).
- **Why:** Lojista decide reposição pelo volume disponível; esconder quebra o north star “balcão confiável”.
- **Fix:** Exibir contagem como metadata secundária visível sob o label (ex.: “142 produtos”), cor muted ≥4.5:1.
- **Suggested command:** `/impeccable clarify` + edit `top-home.phtml` + LESS categoria.

### [P0] Homepage não verificável em produção (503 nginx)
- **What:** awamotos.com retorna página de manutenção nginx; preview bypass também 503.
- **Why:** Impossível validar FOUC, contraste real pós-fix r5, badges clipados, B2B dropdown.
- **Fix:** QA visual pós-liberação nginx em 390/768/1366; Playwright baseline.
- **Suggested command:** `/impeccable audit https://awamotos.com/`

### [P1] Hero marketing vs. balcão catálogo-first
- **What:** Swiper autoplay full-bleed + benefits strip com métrica “5.000+ itens”.
- **Why:** PRODUCT.md pede commerce tool; LCP e atenção vão para promo, não busca/catálogo.
- **Fix:** Reduzir hero mobile; hero estático para B2B logado; remover métrica hero ou integrar ao trust strip.
- **Suggested command:** `/impeccable distill` homepage hero + `b2b-hero-cta.phtml`

### [P1] Scroll fatigue — 4+ shelves idênticas
- **What:** Mais Vendidos → Lançamentos → Bauletos → Retrovisores, mesmo padrão visual.
- **Why:** 5/8 falhas cognitive load; mobile cards ~370px min-height multiplicam scroll.
- **Fix:** Consolidar nichos em tabs; máx. 2 shelves acima da dobra (categorias + 1 vitrine).
- **Suggested command:** `/impeccable layout` + `/impeccable distill`

### [P2] Reorder path ausente na home (Alex)
- **What:** Template `recent-orders` existe mas não está wired em `top-home.phtml`.
- **Why:** Power user precisa recompra rápida; hoje só busca ou área logada.
- **Fix:** Bloco “Pedidos recentes” acima de Mais Vendidos para logados com histórico.
- **Suggested command:** `/impeccable shape` reorder home block

### [P2] Contraste newsletter — fix aplicado, validação pendente
- **What:** Impeccable reportou 1.0:1 em `h2.awa-newsletter-title`; fix r5 no CSS.
- **Why:** Regressão silenciosa possível se cascata legada voltar a `#fff`.
- **Fix:** Validar live; migrar regra para LESS e retirar duplicatas legacy.
- **Suggested command:** `/impeccable polish` footer newsletter

## Persona Red Flags

**Casey (mobile B2B, entre entregas):** Promo bar + header sticky + bottom nav consomem viewport antes do catálogo. Cards altos (~370px) — poucos itens visíveis. Dois affordances de carrinho no header mobile.

**Jordan (first-timer CNPJ):** Três caminhos de cadastro competindo (promo bar, guest notice, faixa B2B, footer). “Ver preços” repetido em cada card sem explicação persistente única. Hero autoplay desorienta.

**Alex (power user reorder):** Sem “Pedidos recentes” na home. Quatro vitrines genéricas antes de utilidade pessoal. “Ver todos” repetido 5× sem prioridade operacional.

## Minor Observations

- Pagination do hero com `aria-hidden="true"` — controles visíveis deveriam ser anunciados.
- Newsletter copy B2C (“promoções por e-mail”) desalinhado com tom atacadista.
- Header bootstrap defer idle na home — sticky/focus pode atrasar no primeiro toque.
- `Super Ofertas` desativado em top-home — boa poda; verificar consistência no menu.
